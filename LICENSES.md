## Not included (and why)

- Karoryfer Big Rusty Drums (CC0): 590 MB of FLAC, far above the size budget; a trimmed selection could be added later.
- Boochi44/free-drum-samples: CC0 is stated in the README but the repository has no LICENSE file.
- Freesound packs: need an account and an API key to download programmatically.
- Legowelt, MusicRadar and archive.org rip collections: no redistribution rights.
